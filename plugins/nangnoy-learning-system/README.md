# Nangnoy Learning System 🧠🎓

A self-improving Thai AI assistant plugin featuring the **Nangnoy Learning Agent** — an AI that learns from every interaction and continuously improves its responses with deep Thai cultural context understanding.

## Features

- **Self-Learning Agent** - Nangnoy AI that remembers, evaluates, and improves from feedback
- **Learning Systems Skill** - Implement feedback loops, critic evaluation, and performance tracking
- **Thai Development Skill** - Thai text handling, business logic, localization patterns

## Included

| Resource | Type | Description |
|----------|------|-------------|
| `nangnoy-learning-agent` | Agent | Thai AI with self-learning capabilities |
| `learning-systems` | Skill | Self-learning feedback loops and performance tracking |
| `thai-development` | Skill | Thai text, date, business logic patterns |

## Installation

```bash
gh copilot plugin install nangnoy-learning-system
```

Or add to your MCP configuration:

```json
{
  "plugins": ["nangnoy-learning-system"]
}
```

## Usage

After installing, start a conversation with Nangnoy:

```
@nangnoy-learning-agent สวัสดีครับ ช่วยอธิบาย Docker ให้เข้าใจง่ายหน่อยได้ไหม
```

Nangnoy will:
1. Understand your question in Thai
2. Provide clear, step-by-step explanations
3. Learn from your feedback to improve future responses
4. Remember effective patterns for similar questions

## Feedback

Use simple feedback to help Nangnoy improve:
- 👍 **"ดีมาก"** or **"ถูกต้อง"** - Reinforces the approach
- 👎 **"ไม่ตรง"** or **"แก้ไขใหม่"** - Triggers improvement
- 💡 **"ปรับปรุงได้โดย..."** - Provides specific guidance
