# Thai Developer Toolkit 🇹🇭🛠️

A comprehensive toolkit designed specifically for Thai developers, covering everything from Thai text processing and business logic to modern backend/frontend development with Docker, Supabase, Flutter, and MCP servers.

## Features

- **Thai Development** - Thai text handling, date/time (พ.ศ.), phone/ID validation, i18n
- **Docker Mastery** - Multi-stage builds, Docker Compose, security hardening
- **Supabase Integration** - Auth, database with RLS, realtime, storage, edge functions
- **Flutter UI Expert** - Thai-optimized mobile/web UIs with Material 3
- **MCP Development** - Build custom Model Context Protocol servers

## Why This Toolkit?

Thai developers face unique challenges that generic tutorials don't cover:

- **Thai character encoding** — UTF-8 handling that actually works
- **Buddhist Era (พ.ศ.)** — Date formatting that Thai users expect
- **Thai business rules** — VAT rates, ID card validation, phone formats
- **Thai UI conventions** — Font selection, line-height, input handling
- **Thai NLP** — Word segmentation for search and AI applications

This toolkit bundles battle-tested patterns for all of these.
